### **CSV Cleaner v1.0**

A simple, fast, and secure web tool to remove duplicate rows from CSV files. This app processes your data entirely in your browser, ensuring your information remains private.

#### **Key Features**
-   **Client-Side Processing:** Your data is never uploaded to a server.
-   **Interactive Demo:** See a live "dirty vs. clean" data preview before you start.
-   **Intuitive Interface:** A single, clean card design guides you through the process.
-   **No Dependencies:** Built with pure HTML, CSS, and JavaScript for speed and security.

#### **How to Use**
1.  Open `index.html` in your browser.
2.  Upload your CSV file and select the column(s) to find duplicates.
3.  Click "Clean My Data" to process your file.
4.  Download the clean CSV file when it's ready.

#### **Project Structure**
-   `public/`: Contains all front-end files.
-   `public/js/app.js`: Handles the core cleaning logic.
-   `public/examples/`: Stores the example data files and the script to display them.
